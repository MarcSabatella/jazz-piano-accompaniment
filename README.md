# Jazz Piano Accompaniment

A plugin add simple piano accompaniment to your leadsheet,
arranged to work as a solo piano arrangement.

## Features

- ** Melody on top: Chords are voiced below the melody
- ** Smooth voice leading: ** Chords are voiced in ways that connect inner voices smoothly where possible
- ** Color tones: ** Appropriate sixths, ninths, fourths, and altered extensions like b9, #11, and b13 are added automatically
- ** Inner voice motion: ** Chords that last more than a couple of beats include moving lines in inner voices (or additional bass notes) for harmonic and rhythmic interest
