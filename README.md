# Jazz Piano Accompaniment

A plugin to add simple accompaniment to your lead sheet,
arranged to work for solo jazz piano.

## Features

The plugin focuses on chord voicing and makes little attempt at doing anything fancy with the rhythm.
But the voicings should closely resemble how most jazz pianists would approach creating a solo arrangement,
and should produce much more pleasing results than the built-in chord symbol playback.

- **Melody on top:** Chords are voiced below the melody
- **Shell voicing foundation:** Chord voicings normally include the root in the bass plus the third and seventh (in either order) above
- **Color tones:** Context-appropriate sixths, ninths, fourths, and altered extensions like b9, #11, and b13 are added automatically
- **Smooth voice leading:** Chords are voiced in ways that connect inner voices smoothly where possible
- **Inner voice motion:** Chords that last more than a couple of beats include moving lines in inner voices (or additional bass notes) for harmonic and rhythmic interest
- **Playability:** Even with the melody on top, neither hand will often need to stretch more than an octave.
